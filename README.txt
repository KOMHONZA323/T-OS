T-OS PROJECT
============

Version: 0.1 Alpha A
Status: Completed Phase A (UEFI, Shell, TGC, TGO)

PROJECT STRUCTURE:
------------------
/T-OS   - Core Operating System source, bootloader, and toolchain.

BUILDING & RUNNING:
-------------------
Go to the T-OS directory and follow instructions in HOWTO.txt or run:
$ bash run_graphical_test.sh

DEVELOPMENT:
------------
T-OS features a custom compiler (TGC) and editor (TGO) for native 
development of C and HolyC applications.
