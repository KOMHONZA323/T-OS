Welcome to T-OS!

Available Commands:
  help      - Show this list
  ls        - List files on disk
  tasm      - Run the T-OS Assembler
  cls       - Clear terminal history
  shutdown  - Power off the system
  reboot    - Restart the system

Usage Tips:
  - Run 'tasm' and enter 'test.asm' to compile.
  - Press TAB for command autocompletion.
